# Easy-Dataset-試用報告

## 1. 執行摘要 (Executive Summary)

- **一句話總結**：Easy Dataset 是一款功能完整且介面友善的 LLM 微調資料集製作工具，極適合需要快速將非結構化文檔轉化為訓練數據的團隊，但需注意 AGPL 授權對商業 SaaS 應用的限制。
- **關鍵發現**：
  1. **多格式支援**：原生支援 PDF, Markdown, DOCX 等多種格式，並具備智慧分詞功能。
  2. **自動化流程**：提供從文本切分、問題生成到答案生成的全自動化工作流，大幅降低人工標註成本。
  3. **直觀介面**：提供視覺化的資料集管理與編輯介面，非技術人員也能輕鬆上手。
  4. **最大潛在風險**：採用 **AGPL-3.0** 授權，若將此工具作為服務（SaaS）對外提供，必須公開原始碼，這對閉源商業產品構成合規風險。

## 3. 重點面向評估 (Key Evaluation)

### 功能完整性 (Completeness)
針對「建立大型語言模型（LLM）微調資料集」的核心需求，本專案覆蓋率極高：
- **資料導入**：支援主流非結構化文檔。
- **資料處理**：內建智慧分塊（Text Splitting）與視覺化調整。
- **資料生成**：整合 LLM API 自動生成 Q&A 與 CoT (Chain of Thought)。
- **資料導出**：支援 Alpaca, ShareGPT 等主流微調格式，以及 JSON/JSONL 格式。

### 系統整合性 (Integration)
- **LLM 介接**：相容所有遵循 OpenAI 格式的 API，這意味著可以輕鬆切換後端模型（如 OpenAI, Azure OpenAI, 或自建的 vLLM/Ollama）。
- **部署彈性**：支援 Docker 與 NPM 本地部署，且資料庫採用本地 SQLite (透過 Prisma)，部署架構輕量，易於整合至現有開發環境。
